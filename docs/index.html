The position line runs from the origin to the body, while the velocity arrow shows its direction, not its magnitude. For a circular orbit, velocity is perpendicular to that line and its speed is sqrt(G * central mass / distance).

Velocity-Verlet updates the moving body's position and velocity under the pull of the fixed central body. Force distance is clamped to 0.05 near the origin, and each animation frame advances four simulation steps, so playback speed depends on the display.

N-body simulation

Every body now pulls on every other body, with no fixed central mass. Bodies start in a ring with random positions and masses, along with sideways velocities that depend on their distance from the center. Drag the view to rotate it, use the arrow keys when the plot is focused, or scroll to zoom.

Simulation settings

Changing settings pauses the demo; start or reset to apply them. The limit of 400 bodies keeps the direct calculation manageable in a browser, while the same seed and settings recreate the starting system.

Each body keeps a color from a repeating palette, while marker size follows mass and the view expands as bodies move outwards. Each step sums softened gravity from the old positions, updates velocity, then uses the new velocity to move every body. With only 120 bodies and G = 0.001, the sideways motion can dominate; increasing G makes the mutual attraction easier to see.

The system uses a direct all-pairs gravity calculation with semi-implicit Euler. It advances four steps per animation frame, so playback speed depends on the device; large time steps can make the motion inaccurate even with softening.
